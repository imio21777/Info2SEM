## 说明

由于存在一些课程的课本实在过大，不方便传输，因此在这里有一些课程的教材还是**建议大家去zlib自行下载**。

同时，这学期还会开设程序设计实践课程，主要是帮助大家考CSP。（CSP考到300分可以免保研的机试，直接满分）经过今年保研，我发现保研机试时间非常之短，且不能带纸质材料，一般来说做三道题就很好了。（一共四道题）这样看来机试会差一些分数，但我认为无伤大雅。

除此之外，如果能考到300分，在811中的科研1中还有额外的2分加分，对于缺少科研分的同学还是比较不错的，但需要大家付出比较多的经历刷题。

**在大AI时代，刷算法题的性价比我觉得是非常非常低的，为什么现在要去人工做AI能秒杀的题目呢。**在我发现这个趋势后，我就没有再刷题了，对CSP也是保有随缘的态度。不过凭借我在大一程设课的老本，还是能考个270。

依我看来，由于CSP不需要自行付费，有学费报销，所以大家可以大胆去考。同时，**如果有其他竞赛奖项能拉满科研分，大可放弃CSP**。但正如我所说，**努力考CSP可**以让这门课拿到2学分的4（对于有些同学，算法2课程似乎也看csp成绩），能加科研分，能免机试，**在有余力的同学那里，还是一个不错的选择**。

我也在这个目录下给大家准备了可以打印上CSP考场的算法模板（也是借鉴于另外的github repo，如有侵权请联系我删除）
