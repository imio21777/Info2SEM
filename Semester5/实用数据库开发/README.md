## 说明

卞昊穹老师的实用数据库开发课程主要通过参加全国大学生计算机系统能力大赛-PolarDB数据库赛道的成绩给分，只要进入决赛第二阶段去线下答辩就是4（我们当年恰好是两队进入）。

考核上，如果进入决赛第二阶段，可以免去期末大作业的报告。但第一份lab还是一样要做的。

难度上，一共会报名5k+支队伍，但最终提交代码的大概是三四百支队伍。同时由于存在外卡队伍（这个可以选课之后自行了解）和作弊队伍，**最终进入决赛20支队伍可能会额外放宽2名以上**。我当年也是非常惊险地以总榜22名（实际19名，最终入围21支队伍）进入了决赛第二阶段。

这门课程最后写代码实际上是一个很迷的存在，因为初赛单纯是调参数，这里**建议大家从拿到账号的第一天就开始进行调参，因为每日提交次数有限，次数越多越有利于进入下一轮**。

决赛的代码框架比较庞大，自己其实很难有动手改的思路，并且让我自己手搓一个量化算法（如RabitQ）也不是很现实。这里也建议大家**趁早着手写代码，并且使用长上下文的AI工具进行辅助**。思路上，则是可以**多向各个老师进行请教**，使用一些并行构建索引、并行搜索的算法。（人大当年有一支队伍也是全国第二，大可放心我们青年教师的水平！）
