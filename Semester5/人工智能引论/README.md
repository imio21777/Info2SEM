## 说明

胡鹤老师的AI引实际上不提供给大家下载课件的渠道。

这门课程的考核主要是让大家**复现一篇A类人工智能领域顶会论文，并在此基础上探索不足**。由每月一次的阶段考核和最终的期末考核组成整体得分，最终还需要通过openi最终提交项目代码和项目报告。除此之外，课堂中还有点名考勤（基本上每节课概率80%）

其中，**阶段考核由助教进行审查，助教会对你的pre提一些问题，包括改进建议和挑战**，只要每个月都有进度推进，并且能可视化出来就可以，一般来说，**在期中前完成复现，后半学期完成一个进阶性的探讨**是比较通常的节奏。

在课程讲解上，我已经不太记得具体的某些课程内容，但非常经典的例如CNN这些机器学习算法肯定是会提到的。这门课单纯作为一门需要学分的同学选修的课程是不错的。正如我所说，这个阶段相对摆烂的同学会多一些，因此你只要真的认真复现了论文，并带有自己的思考，以及满足考勤要求，都能获得不错的分数，胡老师人还是很好的。
