## 说明

并行计算其实是有三位老师一起上课的，且负责的部分不太一样（这门课之前好像是另外的老师教）

具体来说，**考核上是四个lab，一个选做lab，通过obe提交，还有几次小作业，最后有一篇结课论文。**

同时，课程中会穿插约两节课左右的pre，是自由报名的，可以**小组合作或者是单人pre，这部分有额外加分**。

从课程设计上，张超老师主要讲openmp等cpu并行的内容，谢旻辉老师主要负责cuda等gpu并行的内容，而鄂金龙老师负责云与分布式计算的内容。

从得分上来说，只要认真做完作业+lab+final essay，同时做了选做lab，并且报名了小组pre，最后应该是可以拿4的。因为有很多大四的同学不愿意内卷了（

从知识上来说，这门课更像是一门导论课，讲的不会太深，但会简单介绍一些cpu、gpu并行的代码分析与实践，但分布式系统那块更多的是了解，并不会让大家真的去用k8s，去写map reduce等等。

值得一提的是，在保研面试的时候，正好有一道题就是问我关于云和分布式计算我有什么了解hhh。总的来说，作为一门选修课还是很好的。
