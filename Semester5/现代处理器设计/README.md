## 说明

陈文萍老师的cpu设计理论上是很多同学的必修课，整体来说这门课难度有但不是特别大（主要是因为没有非常清晰的教学资源），但陈老师的教学经验丰富，讲解深入浅出，非常适合想了解cpu的同学选择。同时由于网络上资源不是特别多，**建议大家认真上课，课上所讲的内容与小测内容紧密相关**

从考核上，主要由**4-5次课堂小测，7次课后作业和6个左右的实验组成**，期末得分是平时实验最终设计出来的能执行50条指令的cpu的质量。

总的来说，课程容量不算特别大，自己从头写一个cpu这件事也完全可以用AI解决，但是在架构设计上，不同的结构会导致cpu的性能不一致，可能后续的考核会主要看性能。

同时，如果不上课的话，小测可能会做的比较差（小测是不能用AI的）。最后期末还会有一个讲解自己的cpu设计，如果AI写的报告可能全是词语堆砌看也看不懂，为了防止过度AI化，这部分极有可能改为现场提问。所以不管是不是AI，大家一定要对自己的作业负责。

课程前置可以修读的课程有，**数字电路、编译原理和ICS2**。如果已经修了陈老师的数字电路，那么前面四五节课的数电基础理解起来应该非常容易。而编译原理提供的对汇编指令的理解，以及ICS2所学的异常，可以明显帮助大家理解CPU设计的整个流程。当然，就算大家没有修读过，陈老师也会非常详细的讲解，此处完全不用担心。

同样的，最终建议仍然是**认真上课+做所有作业**，小测的话提前复习就不用太担心，只要保证作业都是自己亲笔写的，小测一般没有太大问题（但要防止自己遗忘的一干二净），要注意作业不要用AI生成一个md文件直接提交，陈老师单独在课上展现过非常丑陋的AI提交版本，连格式都对不齐（不知道哪家AI这么蠢）
