## 说明

数据库系统概论这门课理论上一共会开三个班。考核上是由**大概6个lab，期中期末考试，还有一次sql小测组成**。

说实话，我是真的没有学明白这门课程，也不觉得手写sql有什么意义，现在AI写NL2SQL已经非常发达了。但是这门课能让大家理解最基本的数据库架构，同时作为大家的必修课也没法逃掉...

听说陈晋川老师是三个班中风评最好的。陈老师上课讲解还是比较细致的，但我的个人感受是**课程所讲难度与最终考核难度还是有比较大的gap**，且很难找到比较合适的题目进行训练，我当时能做的就是细致化内卷好每一个lab。更何况，我当时sql小测也是回答的惨不忍睹。

同时，我觉得这门课程**理论还是太多了，实操性的东西非常少**，不管是读书还是上课都给我这样的感受，完全不像大二所学的很多真实coding并且看结果的课程，且在课程的后期尤为明显。

非常建议，这门课学习其他的cs类课程，设计更多的分值在同学们的实操上（例如增加实验的可操作性，增加对实验的考察），而不是通过大量理论考试让大家来写代码，或者是背诵八股，感觉这门课程的很多设计理念都是抽象化的。

不过好在，这门课应该是唯一一门，我觉得计算机专业课里理解程度非常抽象的。计算理论导论虽然更抽象，但我更倾向于认为它是一门偏数学的课，抽象的离散数学则是更纯粹的数学课了。

我对这门课真的没有很好的学习方法，大家可以询问其他师兄师姐获得更前沿的意见。但我认为，如果为了小测花费很多时间去练手写sql题，那么真的有些本末倒置了。
