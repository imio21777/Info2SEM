# 商城库存管理系统使用说明

## 系统概述

这是一个基于C++实现的文件系统商城库存管理系统，支持商品管理、库存操作、交易记录查询和数据汇总功能。所有数据以文本文件形式持久化存储。

## 编译和运行

### 编译项目
```bash
make
```

### 运行系统
```bash
./inventory_system
```

或者直接编译并运行：
```bash
make run
```

### 清理编译产物
```bash
make clean
```

## 具体功能使用方法

### 1. 查看商品目录
- 输入选项：`1`
- 功能：显示所有未删除的商品信息
- 显示内容：商品ID、名称、类别、单价、库存量

### 2. 添加商品
- 输入选项：`2`
- 需要输入的信息：
  - 商品名称：如 `苹果手机`
  - 商品类别：如 `电子产品`
  - 商品单价：如 `5999.00`
  - 初始库存：如 `50`
- 注意：系统会自动分配商品ID

### 3. 删除商品
- 输入选项：`3`
- 需要输入：要删除的商品ID
- 功能：软删除商品（不从文件中删除，仅标记为已删除）
- 注意：删除后商品不会在目录中显示，但历史交易记录仍保留

### 4. 进货操作
- 输入选项：`4`
- 需要输入的信息：
  - 商品ID：要进货的商品编号
  - 进货数量：增加的库存数量
  - 操作人：进货操作员姓名
- 功能：增加指定商品的库存，并记录进货交易

### 5. 销售操作
- 输入选项：`5`
- 需要输入的信息：
  - 商品ID：要销售的商品编号
  - 销售数量：减少的库存数量
  - 操作人：销售操作员姓名
- 功能：减少指定商品的库存，并记录销售交易
- 注意：销售数量不能超过当前库存

### 6. 按类别浏览
- 输入选项：`6`
- 需要输入的信息：
  - 类别名称：如 `电子产品`、`服装鞋帽`、`食品饮料`
  - 排序选择：输入 `y` 按库存排序，`n` 不排序
- 功能：显示指定类别的所有商品，可选择按库存量排序

### 7. 查询进销记录
- 输入选项：`7`
- 需要输入的信息：
  - 商品ID：要查询的商品编号
  - 时间范围查询（可选）：
    - 选择 `y` 启用时间范围过滤
    - 开始日期：格式 `YYYY-MM-DD`，如 `2024-01-15`
    - 结束日期：格式 `YYYY-MM-DD`，如 `2024-01-20`
  - 操作人查询（可选）：
    - 选择 `y` 启用操作人过滤
    - 操作人姓名：如 `张三`
- 功能：查询指定商品的交易记录，支持时间和操作人过滤

### 8. 销量汇总
- 输入选项：`8`
- 需要输入的信息：
  - 时间范围汇总（可选）：
    - 选择 `y` 启用时间范围
    - 开始日期：格式 `YYYY-MM-DD`
    - 结束日期：格式 `YYYY-MM-DD`
  - 类别汇总（可选）：
    - 选择 `y` 启用类别过滤
    - 类别名称：如 `电子产品`
- 功能：统计销售数据，支持按时间范围和商品类别筛选

### 0. 退出系统
- 输入选项：`0`
- 功能：安全退出系统，自动保存所有数据

## 数据文件说明

### 商品数据文件 (data/products.txt)
- 文件格式：`ID 名称 类别 价格 库存 是否删除`
- 示例：`1 苹果手机 电子产品 5999.00 50 0`

### 交易记录文件 (data/transactions.txt)
- 文件格式：`记录ID 商品ID 操作类型 操作人 时间戳 数量`
- 示例：`1 1 进货 张三 2024-01-15 10:30:00 100`

## 使用注意事项

1. **输入格式**：严格按照提示格式输入，特别是日期格式必须为 `YYYY-MM-DD`
2. **数据持久化**：所有操作会自动保存到文件，程序退出时数据不会丢失
3. **库存控制**：销售时系统会检查库存是否充足，不允许超卖
4. **软删除机制**：删除商品不会影响历史交易记录的完整性
5. **时间记录**：所有交易操作都会自动记录精确的时间戳
6. **中文支持**：系统完全支持中文输入和显示，表格对齐已优化

## 示例操作流程

### 添加新商品并进行交易
1. 选择 `2` 添加商品
2. 输入商品信息：`华为手机 电子产品 4999.00 30`
3. 选择 `4` 进货，增加库存：`商品ID=新分配的ID 数量=20 操作人=张三`
4. 选择 `5` 销售：`商品ID=相同ID 数量=5 操作人=李四`
5. 选择 `7` 查询该商品的交易记录验证操作

### 查看类别商品和销量统计
1. 选择 `6` 按类别浏览：`电子产品 排序=y`
2. 选择 `8` 销量汇总，查看电子产品在指定时间范围内的销售情况

系统操作简单直观，所有功能都有清晰的提示和错误处理机制。
