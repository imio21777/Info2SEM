# 商城库存管理系统 - Web可视化界面

这是一个为C++商城库存管理系统打造的现代化Web可视化界面，提供实时的数据展示和分析功能。

## 🌟 功能特色

### 📊 核心功能
- **实时仪表板**: 显示关键统计数据（商品种类、总库存、库存总值、交易数量）
- **分类概览**: 商品按类别展示，包含库存和价值统计
- **库存状态**: 可视化显示各类别库存分布（饼图）
- **销量趋势**: 最近7天的销量趋势分析（折线图）
- **交易记录**: 实时显示最新的进货和销售记录
- **商品详情**: 完整的商品信息表格，包含库存状态标识

### 🎨 界面特点
- **现代化设计**: 渐变背景、毛玻璃效果、流畅动画
- **响应式布局**: 完美适配桌面、平板和手机设备
- **直观可视化**: 使用Chart.js实现专业图表展示
- **实时刷新**: 支持一键刷新数据，同步C++系统状态

## 🚀 快速开始

### 前置条件
1. Python 3.x（用于启动Web服务器）
2. 现代浏览器（Chrome、Firefox、Safari、Edge）
3. C++库存管理系统已运行并生成数据文件

### 启动步骤

1. **确保C++系统数据可用**
   ```bash
   # 确保以下文件存在并包含数据
   ls ../data/products.txt
   ls ../data/transactions.txt
   ```

2. **启动Web服务器**
   ```bash
   # 方法1: 直接运行Python脚本
   python3 server.py

   # 方法2: 使用Python内置服务器
   python3 -m http.server 8080
   ```

3. **访问Web界面**
   - 在浏览器中打开: `http://localhost:8080`
   - 界面将自动加载并显示最新的库存数据

### 一键启动脚本
为了更便捷的使用，可以创建启动脚本：

**macOS/Linux:**
```bash
#!/bin/bash
cd "$(dirname "$0")"
echo "启动商城库存管理系统Web界面..."
python3 server.py
```

**Windows:**
```batch
@echo off
cd /d "%~dp0"
echo 启动商城库存管理系统Web界面...
python server.py
pause
```

## 🎯 界面组件说明

### 统计卡片
- **商品种类**: 当前活跃商品总数
- **总库存量**: 所有商品库存之和
- **库存总值**: 按当前价格计算的库存总价值
- **总交易数**: 历史交易记录总数

### 库存状态图表
- 饼图显示各类别的库存分布
- 颜色区分不同商品类别
- 支持悬停查看具体数值

### 销量趋势图表
- 折线图显示最近7天的销量变化
- 实时更新，反映最新销售情况
- 帮助识别销售趋势和模式

### 交易记录列表
- 显示最新20条交易记录
- 支持按交易类型筛选（全部/销售/进货）
- 颜色编码区分进货和销售操作

### 商品详情表格
- 完整的商品信息展示
- 库存状态智能标识：
  - 🔴 缺货（0件）
  - 🟡 库存不足（1-5件）
  - 🟠 库存适中（6-20件）
  - 🟢 库存充足（21件以上）

## 🔄 数据同步

## 🐛 故障排除

### 常见问题

1. **数据加载失败**
   - 检查 `../data/` 目录下是否存在数据文件
   - 确保C++程序已运行并生成了数据
   - 检查文件权限是否正确

2. **端口被占用**
   - 修改 `server.py` 中的端口号
   - 或者关闭占用端口的其他程序

3. **图表不显示**
   - 检查网络连接（Chart.js从CDN加载）
   - 查看浏览器控制台是否有JavaScript错误
   - 确保浏览器支持现代JavaScript特性

4. **样式显示异常**
   - 清除浏览器缓存
   - 检查CSS文件是否正确加载
   - 尝试使用无痕/私有浏览模式
