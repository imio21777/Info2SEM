## TLDR

- 本仓库的内容包括选课建议，课程体验及考核介绍，课程作业等，暂时不更新保研经历
- **不同阶段的任务非常不同**，大一建议大家focus在课设上（即尽可能多的通过线下与网络相结合的方式学习各种必要的基础课程，而不是好高骛远地参考竞赛或者科研），而大二则可以参加一些竞赛，大二下接触科研并于大三专注于科研或者实习
- 不同年级的复习方式大相径庭，高年级在最后一节课总结考点的概率明显提高，在发达的AI工具面前，可以使用**飞书妙记转文字+PPT识别Skill+Prompt**使用AI复习；但低年级时，脚踏实地做一些题、看一些必要的书或blog效果更好
- **数学课决定最后绩点的重要性是最大的。（30学分数理类课程我仅有高数1拿了4）**计算机专业课基本靠努力都可以获得高绩点（本人仅数据库3.7&数科导3.3，其余计算机课程均满绩），但前提是你要付出比别人多的努力卷大作业，小测等。期末虽然是最重要的，但如果平时一直认真听课并完成作业，期末复习压力不算很大。
- **小失误无伤大雅。**我在大二上拿了31学分的3.58，最终年排开出来是11%，仍然入了很多我想入的营。但这一个学期的坑需要其他五个学期去填，导致我二上之后的三个学期都需要非常在意绩点，花费了很多时间在无意义的作业雕琢上。**如果有失误，要及时自我调整心态，但同时要更加全力以赴**
- **尽自己最大可能加入英语实验班**，英实从培养和给分都是独一档的，也能认识到很多好朋友，课程丰富度也是拉满，强推！（且不建议大家因为二外学习退出，这里不详述）
- 每一个Semester文件夹中，是对应该学期的我选修的课程，每一个目录下若有README文件，则是简单给出一些课程学习建议，作业建议或者是考察方式，以助大家能略显从容；具体课程内容（包括Slides、Homework等）在每一个以课程名命名的文件夹中
- 虽然现在是AI时代，鼓励大家尽可能多的尝试先进的模型，但一些好的课程仍然经久不衰，系统性的学习一门语言也是必要的，**不建议一上来就自然语言编程**，完全可以在闲暇之余通过[csdiy](https://csdiy.wiki)进行cs的自学（这真的是非常好的网站！）
- 强烈建议所有cs同学尽可能早的**使用mac并接触linux系统&terminal**
- 基本上所有课程教材和必要的书籍都可以在**zlibrary**搜索到
- **身体健康是远比学业要重要的多的东西，坚持锻炼**

外保的绩点参考是全部平均绩，因此在必要的要求之余还是尽量少选课，以免选到雷课，一门3.0的代价可能是一个学期的努力白费...**RUC的绩点制度是只比四舍五入之后的小数点后两位，因此3.825和3.834其实是一个排名。**本人的亲身经历在法学院莫名其妙吃了区块链相关的四学分3.7...从而导致后续每一门都需要争4才能四舍五入到下一个stage，不然小数点后第三位一直都是以3/4结尾。

在大一暑假的时候，我将我的win本换为mac，故丢失了程序设计学习和大部分数学课学习的一些材料，因此这部分只能给大家提供一些文字建议。其余计算机相关的课程，我会附上我的一些课程作业实现（不可避免地，其中存在错误）

**总结而言，如果你想外保，可以参考我下面的选课模式**：

- 必修课（包括数学、思政和专业课）在对应学期一定要选，且给予足够重视，在可选择的情况下，尽量选择较好风评的老师
- 个性化选修
  - 有一些实际上和必修课性质差不多，例如只在特定学期开，且剩余可选的课不开了（例如CPU设计），这些也尽量在对应学期选上（因为考核实际上没有那么难）
  - 风评差/学习有难度（例如安全类课程）的课程可以放到大四在选，因为个性化选修不需要在保研前修完
  - 可以通过向身边同学了解给分好的课，并靠自己的努力拿到4
- 尽自己最大可能加入英语实验班（这里不详述）
- **非必要不选择任何选修课程（这里包括专业个选和基于爱好的个选），除非你有100%的把握拿到4，或你的绩点不在乎微小的波动（我在这上面吃的亏足以让我最终绩点至少提高0.02，排名至少提高2名...）**
  - 如果你真的真的实在喜欢某门课程，可以选择旁听从而不影响绩点，这件事情也不会影响你参营时候老师质疑你没有修习过金融相关课程（例如你作为信院同学想修一门投资学）
    > 这里分享一个小故事，我选修钟老师的ERP沙盘模拟是因为当时得知第一名的组是全员4。但这门课也有一些运气原因，我们组因为一个决策失误最终只拿到第二，导致全组满绩点的设想泡汤。但我的努力感动了我的组员（实在感谢**鑫鑫文化有限公司**），最终组员投票把每组有一个4的名额给了我。除此之外，由于我的体育成绩不错（三年体测均分均>90），我在体育课的选择上选择了吴老师的体质健康（这门课真的很好！），从而能稳拿到一个4。这件事告诉我们，其实很难有你能坚定自己拿到4的选修课，因此，在绩点边缘的情况下，还是建议往后选。
- 数学课最重要的是期末，可以说期末占80%，其他占20%（包括期中，调分懂得都懂），一定要注意数学课的绩点（我数学课均绩甚至<3.6）
- 体育课如果对自己没有把握可以放到大四（如游泳），但还是建议大家认真锻炼身体并且早日修完前四学期要求的四门体育课

## 课程难度概况

为了方便大家更直观的理解课程，我结合自己的上课体验，对课程进行了多维度的评价。由于不支持排序功能，所以大家只能通过搜索的方式在庞大课程中查找。

由于同一课程不同老师存在差异，这部分暂不在此部分讨论，客观的关键指标，所有课程的评价都仅基于我选择的老师（以缩写标注）

- “课程难度”：客观而言，我认为这门课程的难易程度，例如是否概念很抽象，理解很复杂等
- “考试难度”：对于有期末考试的课程，期末考试的难度（相比于平常课程所学或作业题），无期末考试的课程此处为无
- “学习难度”：完成课程日常作业、大作业、小测等需要的付出程度
- “绩点程度”：获得4.0的绩点需要付出的努力程度
- “随机程度”：尽管付出同样的努力，仍然可能获得比较低绩点的概率

### 数理类课程

个人的体感是数学类课程都是比较难的...且每年的难度可能不尽相同。由于人大基本上不会外泄往年题（至少我基本没找到），且考试难度较大（基本对标考研难度），这部分还是需要给予足够重视。

我参加过高数和高代的好多节习题课，体感是张老师高代1的习题课难度高于考试难度，高代2书本课后题难度又低于考试难度，因此做课后题对期末考试帮助几乎为0（可能是我没找对题）。与之相反的是，高数1&2则是通过广泛的刷题会有比较好的表现。**此处呼吁有学习方法的同学给一些刷题或者学习建议**

同样的，概统最终考试难度也远高于使用的浙江大学课本，期中考试复习PPT的题目较为有用，但期末毫不相关...且千万不要相信期末重点是后半学期...

反倒是离散数学是里面最为人性化的课程，虽然课程难度大，但考试与课程关联度高，只要用心结果都不错（且不用和其他理科学院同学竞争）

不过更详细的课程体验和考核，可能还是需要大家去询问一些应届师兄姐&自行体会。不过我的建议是，其实cs的同学对于微积分不需要掌握特别强的功底，如果不做量化，数学课对后续的学习帮助也非常微薄，例如机器学习课程也不会真的让你手推一些矩阵运算。**绩点的意义已经远大于课程本身了。（强烈呼吁课程改革）**

### 专业核心课

**可以说，在AI的加持下，基本所有课程的大作业都要败下阵来，但这不代表这些课程丧失了学习的价值。**以下这些课程中，数据库可能是上起来最折磨最抽象的（计算理论虽然抽象但是相对有迹可循），同时我也认为只有这门课存在随机性，其他都可以靠自己的努力拿到4

在23年，完成一道程序设计1荣誉的编程题，可能10篇blog都难以最终让我写出代码，但如今已经可以被顶尖模型秒杀，且两门程序设计课程已经合二为一，但学好一门编程语言仍然是重要的。**你也许可以用顶尖模型秒杀ICS的任何一个lab，但你仍然有必要去阅读AI的代码实现，并感受那些精妙的系统设计。**

总的来说，程序设计虽然是大一的课程基础，但容量可能不足以支持cs专业的同学学习，大家可以适当通过网络提前学习一些课程。**如果你在大一结束前，都没有学会使用github和terminal，那你绝对是不合格的。**大二会有非常多的专业课，大家也会感受到计算机的庞大体系，合理使用AI可以帮助大家提前学习或课后补缺。这里值得说的是，图灵会导入这些课程，虽然相对难一些，但这些课程的教学质量确实是天花板了，学习体验其实会相对大类更好。（建议有余力的大类同学也前来感受hhh）

其实真的上完之后，我会觉得我还挺喜欢这些课程的，例如在ICS中发现电脑远远能做比我想的更多的事情，相较于表面的代码，我可以操控更多东西。这里欢迎所有感兴趣的同学，在大三的时候加入ICS助教，为课程改造出一份力！

### 思想政治理论课

思政课给分实际上与老师有非常大的关系，可能还有一部分依据是出勤，但最大头的还是期末考试（感觉期末考试占比也远高于实际写出来的）这部分建议先向身边同学了解一下不同老师的风格，然后再做选课选择。不同学院分配的老师选择不一样，也可能出现轮换的情况，所以可能要广泛地问一问。

这部分课程给分随机实际上是比较大的。我对于这部分课程会选择**考前一天晚上把整本教材从头到尾看一遍**（思修除外），实话说，能感受到很多教材在编撰时都非常用心，也真的能学习到一些历史和理论，更何况，要不是有期末考试，我可能永远都不会完整读完...

这里需要说明的是，**马原建议大家提前整理一些必背重点**，然后再看书，因为这其中对标准回答的要求比较高。但其他课程，例如史纲有名词解释题，实际上读完一本书，就能回答出大概。与其背诵别人整理的重点，不如自己跟随教材自学一遍。

**这部分建议大家的心理预期调整为一半4，一半3.7即胜利。**

### 体育

23级是必修太极拳和游泳的。其余体育课程我选择了自己喜欢的跑步相关课程外加自主锻炼。**体育课很大一部分给分依据在于出勤和体测分数**，因此保留自己在高中锻炼下来的强壮身体比较重要。李广亮老师是很好的体育老师，在课程丰富多样的同时会有美味的鸡汤喝😋，课程强度也不是很大，且很尊重同学，同学们在课程上也非常团结，强烈推荐～

### 大学英语类

我的英语分级是英语实验班，因此需要修10学分（2+2的英语+2英语辩论+2英语演讲+第二外语）。**英实优秀率似乎是80%，因此只要你正常上课完成任务就能拿4**。同时英实的课程难度也完全足以让你学习到一些英语知识和国家文化，也完全有自我展示的机会。

值得一提的是，在第一学期修的英语演讲和第二学期的英语辩论都是略有压力且非常充实的课程，能够极大保持自己的口语水准，也对四六级备考很有帮助。我当时甚至连题型都不清楚，裸考也都拿下630+。英实的小伙伴都很热情且很有实力。（有小伙伴cet6 700+&对于各种听力复述程度极高...）林老师也非常美丽善良，强烈推荐～建议大家沉浸式享受演讲和辩论这两门课，而不是一味想着如何获得更高的得分。（怀念tice...这可能是你大学唯一能沉浸在英语中的机会了）

对于第二外语（这个是有30%优秀率限制的），我当时害怕影响我的绩点就退出了，但结果后来补修英B的英语课还是吃了3.7，还因此丧失了最终的结业证明和学习多一门语言的机会，实属可惜。

## 结语

最后，感谢中国人民大学信息学院、中国人民大学明理书院对我的培养，以及给我的支持。当时区块链协会遇到困难，游伟老师给了我很有用的建议，并找到明理书院获得了许多支持，让我能在区块链领域做探索。在我对未来迷茫的时候，班主任王晶老师也给了我很多有用的建议与支持。信院的很多行政和教务都是非常高效和给力的，团委、党委也会非常虚心听从学生的建议。还有太多老师的令人惊叹的教学水平和无比精彩的课程，在此不一一枚举，但我内心无比感激。

在信院学生会任职三年，从干事到部长，最终成为主席，也看到信院在一天天变好。（虽然还有很多要改进的地方）如果还有机会，我可能会改变我的选课策略，从而不用这么在意绩点。那样的话，我就能有时间去参加更多活动了。很遗憾，我没有参加特别多的社会实践活动，没有参加运动会，歌舞晚会，125等等，也很早就从国旗班退出，这些似乎都是为绩点所害。**如果你看到这里，希望你能享受自己的大学生活，而不是拘泥于那一个数字，要尽情地生活。**往身边看，我在人大的很多朋友也都取得了自己满意的结果。从更长的尺度看，那一节习题课对最终绩点的影响是无足轻重的，但某一场活动给你带来的冲击，可能是经久数年的。

**希望我的选课建议能帮助到那个迷茫的你。希望你能在人大收获属于自己的黄金四年。希望信息学院永远是你的家。**
