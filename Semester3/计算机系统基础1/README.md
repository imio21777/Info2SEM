### 学习建议

ICS的课程考察主要由**平时作业、课程实验（lab）、期中考试和期末考试四部分组成**。

平时作业目前靠AI正确率应该还是很高的，课程实验基本在思路正确的情况下也可以靠AI做个大概。

但这里的建议是，**务必自己完整的了解每一个lab的解法**。可以在互联网上搜索每一个lab的解法，有非常充分的指导和思路分析（当然也可以看我的report），务必自己复现成功并且明白每一步为什么这么做。

**同时，CSAPP是一本很好的书，就算平时没时间看的话，也一定要在期中和期末之前看一遍。**看书是非常好帮助你理解课上没明白的知识点的方法。

对于期中和期末考试，风格还是相对比较随机，一般来说期中会比较难（但有调分在，大家不必太担心）。实际上最好的复习方法就是认真上课+做作业和实验+看书，完全足够了。

我并不推荐大家去刷北大题，最后你是否学明白这门课程不在于是否刷了北大题，也不在于那几道选择题，而是你怎么理解计算机系统。

在上课之余，我还是更推荐去看CMU的[15-213](https://www.cs.cmu.edu/afs/cs/academic/class/15213-s26/www/)。你可以在上课前看，也可以作为复习课看。但不管怎么说，如果你认真上课了，认真看了网课，也认真看了书，并且自己吃透了每一个lab，那4.0肯定是手到擒来的。

值得一提，柴老师的教学水平很高，所以相比于只听CMU的网课，你在线下也绝对能学到更先进的东西（在ICS2尤为明显）
