### 学习建议

李德英老师是非常好的老师哈哈哈！因此大家不用担心绩点爆炸的情况。

离散数学本身比较抽象，听不懂课，或者上完课也不会做题非常正常，有一些做题方法可能只能靠背诵（也许是我太笨了）有一些抽象的数学概念确实超出了我的理解范围...

同时，李老师对作业的要求不是特别高。但实际上认真做一遍作业还是有必要的，至少需要认真做前面量词部分的（因为有一个期中考试），但说实话这部分是非常简单的。

对于后半学期的抽象内容（群环域那些），要注意**听课上重点强调的例题**。虽然期末前还会再次强调，但如果没上课的话，自己看证明可能会看不懂...（但现在AI也比较发达就是了）

期末考试有20%+会是发挥类的题目，这部分我是答不上来的，但要把自己会的知识点写上去。因为可能这道题考的就是你想的那个知识点，只是你不会运用。（例如有个拉格朗日啥的，我已经有些遗忘了）

总的来说，保持上课+认真写作业+考前复习，3.7应该是不难的，相信李老师。
