### 学习建议

算法1的作业包含日常代码作业、纸质几道题（这个未附上）和一个dijkstra的大作业。现在AI应该都可以直接秒杀。

课程上，我一开始听张静老师的课是有些许不适应的。会觉得讲的比较快，属于完全不能开小差的那种。但听了几节课之后会觉得，节奏是非常合适的，不快也不慢，但你要是开小差就要注意了...例如讲一个新的数据结构，比如红黑树，如果你没有一开始认真听一些定义，后面也许就会有些迷茫。

但总的来说，听一遍张静老师的课，应该就能当场消化掉课程内容。**对于课堂小测，不放心的同学可以做王道考研对应章节的题目，基本完全能够handle。**当然存在一些书里面没有的，那基本看看PPT复习就可以了。

不过经常会出现，我今天课上学明白了，周末就忘的精光的情况。这里同样祭出B站。**张静老师的课程实际上和邓俊辉老师的PPT，教授内容都基本一致，完全可以在课后反复学习。**同时也建议期末考之前把整个网课过一遍，能大大加强做题手感（因为很多题目是刷不到的）

其实上述这一切都能做到的话，4.0应该还是比较容易的。我当时期末的时候跳了一道红黑树的题，最后做完卷子忘记回来做了（好像有5分），直接是空着的，但最后仍然有4.0。
