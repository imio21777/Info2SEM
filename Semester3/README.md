## 说明

关于概率论与数理统计，由于PPT内容覆盖了我的很多笔记，可能不太方便大家的观看了，这里就不再单独开一个文件夹了。

概统的考察，是**作业+考勤+期中期末考试**。

赵老师的要求比较严格，作业都是提交**纸质版**，而不能提交电子版，这也是一种考勤的考察方式。

同时，赵老师上课也会随机点名，所以这门课对出勤的要求还是比较高的。

概统整体上讲解内容不是很难，大家通过自学浙大教材实际上也能感受到这一点（毕竟应该是专门给工科设计的）。

我想提醒大家的是，**这门课归根结底还是一门数学课，和人大大大小小的数学课大相径庭**。因此，期末考试绝对是重中之重。我后来反思这门课为什么我吃了3.0，最主要的原因是因为老师最后说考试重点在后半学期，从而我几乎没有复习前半学期的内容。拿到考试卷后发现，后半学期所学习的估计相关的内容只有套公式（且公式都给出了），前半学期的内容则占了60-70%之多，让我应接不暇。

**期中考试与PPT紧密相关，甚至可能出现PPT原题**。

**期末考试题难度与PPT、课本均没有关系，且属于高于这两者的难度**。我记得当年考了一道分段求概率密度的，直接败下阵来（因为课上没讲过分段）。由于本人没有做过卯书，所以不太清楚难度相关性，如果学有余力的同学可以尝试，但绝对不要用浙大课本课后题复习了，难度远远不够。
