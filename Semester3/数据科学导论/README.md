### 学习建议

数科导确实是一个比较随机的课。个人觉得课程内容并不难，且范举老师讲课节奏比较舒缓，ppt也非常直观，相对非常容易理解（哪怕不上课）

从考察上，当年是有**两次笔试作业，一份大作业，一次期中上机测试，一次期末测试。**

笔试作业在当时就可以通过AI解决，现在更是不在话下。

大作业也并不难，当时还采取了小组合作的形式（3人），现在更是可以AI秒杀，当时设计的初衷应该就是让大家熟悉Python语言。

同时，为了让大家熟悉PY，一开始一个月还有一个网站测试需要大家完成，且期中考试是不可带纸质材料的机考python（实话说我觉得这个非常搞笑）

由于我写C++远大于python，python中很多函数我也基本是即查即用，更何况现在发达的AI完全可以做到NL2Code，所以这部分当时10道题我好像只做了3道，周围同学也基本表现比较差。（主要是有一些函数考察太阴间了，数据清洗这种事我也都是AI做的）这里可以补充一下，我拿了数学建模全国二等奖，里面的代码基本都是python，也基本都是自然语言coding出来的，数据清洗也完全是自然语言完成的，所以我很质疑现在还要手写代码的必要性。

回到课程本身，后续很多思想，包括贝叶斯概率，pagerank，熵等等概念，到后面的学习可能还会重复出现。（例如在ML中）但本身这些概念理解起来并不难。

虽然这门课我最终只拿了3.3，我也自认为我期末都答得很好（因为当年题量比较大延长了20min，而我两小时之内就已经做完了），但我还是觉得如果你缺少一门选修课，这门课是可以选择的。当时我提前在B站看了一些机器学习基础，可能会有一些帮助。

不过这里还是建议，取消手搓python这种古法考核内容吧...
